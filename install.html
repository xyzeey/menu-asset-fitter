메뉴 에셋 플러그인 설치

한 번만 설치해두시면 됩니다. 새 버전이 나와도 파일만 덮어쓰면 됩니다.

플러그인 내려받기
늘 최신 버전입니다. 여기서 받아주세요.

먼저 확인

Figma 데스크톱 앱을 먼저 설치해주세요. 브라우저에서 연 Figma로는 이 플러그인을 쓰실 수 없습니다. 앱이 없으시면 figma.com/downloads 에서 받아주세요.

위에서 loungex-product-asset.zip 을 받아주세요.

설치하기

  1. Figma 데스크톱 앱을 열어주세요.
    아무 파일이나 하나 열어두시면 됩니다.
  2. zip 을 풀어주세요.
    계속 둘 자리에 풀어주세요. 다운로드 폴더처럼 나중에 정리하는 곳 말고, 문서 폴더 안 같은 곳이 좋습니다. 나중에 폴더를 옮기면 다시 설치해야 합니다.
  3. Figma 에서 ⌘ / 를 눌러 검색창을 띄워주세요.
    윈도우를 쓰시면 Ctrl / 입니다.
  4. import plugin 이라고 치신 뒤 Import plugin from manifest… 를 골라주세요.
    메뉴로 가셔도 됩니다 · Figma 아이콘 → Plugins → Development → Import plugin from manifest…
  5. 파일 고르는 창에서 압축을 푼 loungex-product-asset 폴더로 들어가 manifest.json 을 골라주세요.
    이 폴더 위치를 Figma 가 기억합니다. 이후로는 옮기지 말아주세요.
  6. 설치가 끝났습니다.
    따로 알림은 뜨지 않습니다. 아래대로 한번 실행해보세요.

실행하기

⌘ / 를 누르고 product asset 이라고 쳐주세요.

또는 캔버스 빈 곳에서 우클릭 → Plugins → Development → Lounge'X Product Asset 으로 들어가셔도 됩니다
일반 플러그인 목록이 아니라 Development 아래에 있으니, 안 보이면 이 경로를 먼저 확인해주세요.

쓰는 법

창 위쪽 버튼에서 넣는 방식을 골라주세요. 두 가지가 있습니다.

기존 컴포넌트에 넣기 이미 있는 컴포넌트 세트에 새 variant 로 넣습니다. 세트 왼쪽 라벨도 같이 만들어 줍니다. 기본값입니다.
새 컴포넌트로 만들기 세트에 넣지 않고 독립 컴포넌트로 만듭니다. 이름이 카테고리/이름 형태라 에셋 패널에서 폴더로 묶입니다.

기존 컴포넌트에 넣기

  • 위쪽에서 페이지 와 적용 컴포넌트 를 골라주세요.
    지금 열려 있는 페이지가 기본으로 잡힙니다. 다른 페이지에 있으면 바꿔주세요.
  • 이미지를 끌어다 놓아주세요.
    여러 장 한꺼번에 넣으셔도 됩니다.
  • 이미지마다 속성 값을 채워주세요. name= option=
    이미 쓰던 값은 눌러서 골라주시고, 없는 값은 그냥 쳐주세요.
    제주 유기농 말차라떼의 아이스 이미지라면
    name= Jeju Organic Match Latte  ·  option= iced
    option= 은 이미지를 보고 적어주세요. 아이스면 iced, 핫이면 hot 입니다.
    food · goods 는 option= 이 없습니다. 종류를 name= 쪽에 넣어주세요.
    바움쿠헨 플레인의 이미지라면
    name= baumkuhen plain
  • 같은 상품끼리 묶인 상자를 확인해주세요.
    상자 머리의 새로운 상품 · 기존 상품 표시를 봐주세요. 새로운 상품이면 줄이 하나 늘고, 기존 상품이면 그 줄 옆 빈 칸에 들어갑니다.
  • 새로운 상품이면 상품명 을 한글로 적어주세요.
    옵션 은 넣는 이미지에서 자동으로 채워지니 그대로 두셔도 됩니다(HOT/ICED 처럼). 고치셨다가 되돌리려면 자동으로 를 눌러주세요.
  • 아래 만들기 를 눌러주세요.
    경고가 붙은 이미지는 준비됨 개수에서 빠지니, 먼저 확인해주세요.
food · goods 처럼 옵션 속성이 없는 컴포넌트에서는 상품 과 옵션 칸이 따로 생깁니다. 이름만으로는 어느 상품인지 정할 수 없어서입니다. 상품 을 눌러 이미 있는 상품에서 골라주시고, 없으면 새 이름을 쳐주세요.

새 컴포넌트로 만들기

  • 이미지마다 영문 이름을 적고 카테고리 를 골라주세요.
  • 여러 장이 같은 카테고리면 전체 적용 을 눌러 한 번에 맞춰주세요.
    만들어지는 이름은 drink/coffee/americano-ice 같은 형태입니다.

새 버전이 오면

이 페이지 맨 위에서 zip 을 다시 받아, 풀어서 기존 폴더에 덮어써주세요.

폴더 위치만 그대로면 다시 설치하지 않아도 됩니다. Figma 는 실행할 때마다 그 폴더의 파일을 새로 읽습니다. 덮어쓴 뒤 플러그인 창을 닫았다 다시 실행해주세요.

이미지 준비하기

파일 형식배경이 투명한 PNG
최소 크기400 × 400px 이상
만들어지는 것120 × 120 컴포넌트

여백은 신경 쓰지 않으셔도 됩니다. 플러그인이 투명한 부분을 알아서 잘라내고 크기를 맞춰줍니다. 다만 배경이 안 지워진 이미지는 넣어도 막히니, 배경을 지운 뒤에 넣어주세요.

잘 안 될 때

플러그인이 목록에 없습니다
데스크톱 앱에서 여셨는지 확인해주세요. 앱이 맞다면 Plugins → Development 아래를 봐주세요.
어제까지 되다가 안 됩니다
폴더를 옮기거나 지우셨을 수 있습니다. 위 설치 과정을 처음부터 다시 해주세요.
고쳤다는데 그대로입니다
플러그인 창을 닫았다가 다시 실행해주세요. 그래도 그대로면 이 페이지에서 zip 을 다시 받아 기존 폴더에 덮어써주세요.
넣을 컴포넌트가 목록에 안 뜹니다
위쪽 페이지 드롭다운을 확인해주세요. 지금 열려 있는 페이지로 맞춰져 있으니, 다른 페이지에 있으면 그 페이지를 고르시거나 모든 페이지로 바꿔주세요.
경고가 떠서 만들 수가 없습니다
빨간 글씨에 이유가 적혀 있으니 읽어봐주세요. 대부분 배경이 투명하지 않거나, 이름이 이미 있는 경우입니다.
