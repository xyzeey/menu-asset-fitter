# Menu Asset Fitter

메뉴 이미지를 규격에 맞춰 잘라내고 가운데 정렬해 내보내는 웹 도구.

**→ https://xyzeey.github.io/menu-asset-fitter/**

Figma 플러그인 설치 안내 → https://xyzeey.github.io/menu-asset-fitter/install.html

| 규격 | 값 |
|---|---|
| 캔버스 | 120 × 120 |
| 콘텐츠 영역 | 96 × 86, 위치 (12, 22) |
| 크기 | 투명 여백을 제외한 실제 내용이 영역에 들어가는 최대 크기, 비율 고정 |
| 정렬 | 영역 기준 가로·세로 가운데 |
| 내보내기 | 480 × 480 PNG |

## 쓰는 법

페이지를 열고 이미지를 끌어다 놓는다. 투명 여백을 잘라내고 규격에 맞춰 배치한 PNG 를 내려받을 수 있다.

**배경이 투명한 PNG 를 400 × 400px 이상으로** 넣어야 한다. 여백은 신경 쓰지 않아도 된다.

판정은 셋이다.

| | 조건 | 내려받기 |
|---|---|---|
| 통과 | 문제 없음 | 가능 |
| 경고 | 4배로 내보내기엔 원본 해상도가 모자람 | 가능 |
| 오류 | 배경 불투명 · 전부 투명 · 못 여는 파일 | 막힘 |

이미지 처리는 전부 브라우저 안에서 일어난다. 어디로도 올라가지 않는다.

`index.html` 파일 하나만 받아서 열어도 똑같이 동작한다 (`tokens.css` 와 `assets/` 가 같이 있어야 글꼴이 나온다).

## 고치기

소스는 `src/` 에만 있다. `index.html` 은 빌드 산출물이라 직접 고치면 다음 빌드에 덮어쓴다.

```
src/body.html   마크업 + 스크립트
src/page.css    이 페이지 전용 규칙 (색·타입은 전부 XDS 토큰)
src/build.py    index.html 을 만든다

python3 src/build.py
```

규격을 바꾸려면 `src/page.css` 와 `src/body.html` 의 `AREA`, 내보내기 배수는 `src/body.html` 의 `scale` 을 고친다.

## 디자인

XDS(`tokens.css`)를 따른다. 라이트 전용. 버튼 · 배지 · 체크박스 · divider · upload-dragger 는
디자인시스템 컴포넌트를 그대로 옮겼다.

상태 색만 예외다. `--semantic-static-caution` 등은 흰 바탕에서 대비가 2 안팎이라 글자로 쓸 수 없어,
색선과 칠에는 semantic 토큰을 쓰고 **글자만** 대비가 나오는 단계로 내렸다.

## 같이 쓰는 것

Figma 플러그인이 따로 있다. 이미지를 넣으면 같은 규격으로 배치해 컴포넌트로 등록해준다.
플러그인 소스는 이 레포에 없고 공유 드라이브로 배포한다.
설치 방법은 [install.html](https://xyzeey.github.io/menu-asset-fitter/install.html) 참고.

- 피그마에 넣을 거면 → 플러그인에 **원본**을 준다. 원본을 그대로 품고 보이는 범위만 조정하므로
  나중에 규격이 바뀌어도 화질 손실 없이 다시 만들 수 있다
- 앱 · 키오스크 · DID 로 바로 넘길 거면 → 이 웹 도구로 뽑는다
